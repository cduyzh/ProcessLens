# ProcessLens 图标规范

## 应用图标

- **含义**：中央处理器轮廓承载实时脉冲，表达进程、资源占用和持续监测。
- **底板**：浅雾白圆角方形，1024 坐标中的安全范围为 `(72, 72, 880, 880)`，四角半径 196，外部透明。
- **主体**：深色芯片与内凹监测屏幕；金属引脚保持低对比，在小尺寸下优先保留主轮廓。
- **色彩**：雾白 `#FBFCFF` / `#E4EAF1`，石墨蓝 `#182638`，屏幕 `#112330`，脉冲青绿 `#6CF0CC`，指示灯蓝紫 `#A298FF`。
- **材质**：细腻的渐变、短投影、轻微青绿反射。避免大面积霓虹和过强高光。
- **文字**：应用图标不含文字，不以首字母缩写替代图形识别。

源文件为 `scripts/generate_icon.swift`，使用 AppKit 原创矢量绘制，不依赖图片素材、字体或第三方包。各尺寸由同一组矢量坐标重绘，再使用系统 `iconutil` 生成 ICNS。1024 PNG 为设计预览与外部展示用途；应用内加载 `AppIcon.icns`。

```sh
swift scripts/generate_icon.swift
```

## 功能图标

界面功能统一使用 SF Symbols 的系统语义和统一线宽，便于适配 macOS 显示缩放与辅助功能。侧栏图标采用圆角容器和克制的功能色，选中状态配合背景、标题和图标共同指示。CPU 使用芯片，内存使用内存条，磁盘使用存储盘，网络使用网络连接，详情使用信息圆圈；结束进程和强制退出使用明确的停止语义并配合确认文案。不可仅凭颜色区分危险操作。

## 打包约定

- 应用包：`.build.noindex/cduyzhProcessTool.app`。
- 最低系统版本：macOS 14.0。
- Bundle ID 与稳定 designated requirement：`com.cduyzh.process-tool`。
- 版本由根目录 `Info.plist` 提供，作为有 Dock 图标的常规应用运行。
- `build_app.sh` 只编译、打包并验证 ad-hoc 签名；安装和启动由用户决定。
